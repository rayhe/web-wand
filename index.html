    Motion

    The motion sensor can sit any way round inside the wand. The page has to know which way is which, so the model turns the same way your wand does.

    Or set it now. Press a button, get into position, and it captures once you've held still for a second:

    1. Point the wand straight up.
    2. Hold it level, pointing away from you, grip buttons facing up.
